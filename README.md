# Места знакомые

Браузерная игра: Россия и зарубежные страны, пять уровней, три варианта ответа и пять попыток на уровень.

Откройте `index.html` в браузере. Интернет, установка и сборка не нужны. Прогресс сохраняется в этом браузере на этом устройстве. При переходе на другой адрес сайта или другой браузер сохранение не переносится автоматически.

Игра: https://tatyanababenkova.github.io/voyage/

Репозиторий: https://github.com/TatyanaBabenkova/voyage. Сайт работает на GitHub Pages без сборки.

## Файлы

- `index.html`, `style.css`, `app.js` — интерфейс и логика.
- `data.js` — названия, описания, категории и условная сложность объектов.
- `answers.js` — дополнительные названия похожих объектов для редких категорий. Это варианты ответа, а не дополнительные фотографии.
- `assets/*.jpg` — уменьшенные копии фотографий для игры. Номера соответствуют исходному реестру.
- `photo-licenses.json` — источники и сведения о лицензиях CC0 / public domain. Поле sha256 относится к исходному скачанному файлу, а не к уменьшенной игровой копии. Фотографии уменьшены и перекодированы в JPEG.

Word-реестр всех 250 фотографий: [docs/photo-registry.docx](docs/photo-registry.docx). Машиночитаемые сведения об источниках находятся в `photo-licenses.json`. Исходные фотографии и сохранённые подтверждения лицензий хранятся отдельно от репозитория. Требования указания авторства для выбранных лицензий отсутствуют; сведения об источниках сохранены для проверки происхождения. Лицензия фотографии не является отдельным разрешением на изображённые произведения, товарные знаки или иные права третьих лиц.

В каждой новой партии случайно выбираются 50 уникальных объектов одного режима, затем распределяются по пяти уровням сложности. Порядок внутри уровня перемешивается. При перезагрузке сохраняется выбранная партия: повторные загрузки не подменяют вопросы. У России и мира отдельный прогресс.

Варианты ответа случайно выбираются из той же категории объекта и перемешиваются. Приоритет — другие фотографии того же режима; для редких типов используются дополнительные названия из банка ответов. Неверный вариант блокируется; повторное нажатие не расходует попытку. После потери пяти попыток повторяется текущий уровень, альбом и завершённые уровни сохраняются. «Новый маршрут» заново выбирает вопросы, но не очищает альбом.

Фотографии показаны в одинаковых рамках с кадрированием без растягивания. Нажатие на фотографию или значок лупы справа сверху открывает снимок целиком. С клавиатуры: Tab на фотографию, Enter; Escape закрывает снимок. Ответы — клавиши 1, 2, 3. Основные экраны рассчитаны на доступную высоту окна; альбом разбит на страницы. На очень маленьких окнах или при сильном увеличении масштаба браузера доступна обычная прокрутка, чтобы не прятать содержимое.

Сохранение первой версии игры переносится при первом запуске обновлённой версии на том же адресе. Локальный файл и сайт GitHub Pages имеют разные хранилища браузера.
